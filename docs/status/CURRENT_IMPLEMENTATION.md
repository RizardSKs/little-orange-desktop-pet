## 当前已实现

### 成长、照顾与存档

- 等级上限为 50；1–20 级有独立称号，20 级进入闪耀阶段，之后每 5 级增加一颗闪耀星，50 级达到六星圆满。
- 1–20 级经验曲线约为旧版三倍；schema 1 旧档迁移时保留等级并按新曲线换算当前经验，不清除金币、装扮、设置或位置。
- 四项照顾属性继续按运行时间变化；只有确实恢复属性的照顾才扣除资源并发放对应经验，满属性不能反复刷取。
- 金币和经验只在应用进程实际运行时产生。关闭应用或 Windows 进入睡眠、休眠等系统挂起期间不发金币和经验；重新进入时只结算最多 8 小时的属性变化。仅锁定 Windows 屏幕时，进程仍继续在线奖励、效果和探索。
- 存档升级为 schema 2，具有字段级深层校验、schema 1 到 schema 2 的迁移、迁移前版本化备份、主档损坏后的备份恢复和未知 schema 拒绝覆盖。

### 桌面行为与互动

- 桌面锁定会固定位置、强制置顶、停止自动散步、隐藏管理面板，并让桌宠主体完全鼠标穿透；独立小锁窗口、托盘和应用菜单可解锁，设置会跨重启保存。
- 单击抚摸、双击打开面板、连续点击躲闪；拖动时进入拖拽姿态，松手播放落地动作并立即保存位置。
- 鼠标互动默认开启，包括视线跟随、靠近陪伴、扒拉、被光标带动、追逐和转晕，并有优先级、冷却和打扰频率限制。
- 键盘陪打默认关闭，首次启用必须确认隐私说明。原生组件只在本机累计 250 毫秒时间桶内的按键次数，不读取、传递、保存按键内容、字符、密码、输入法内容或活动窗口；组件不可用时安全降级，不阻止应用启动。
- Windows 系统挂起会暂停原生输入与实际运行时，并在恢复后重建运行时基线。锁屏会暂停原生键盘钩子与光标采样、收束鼠标环境位移互动并停止自动散步；全屏前台会暂停环境互动。锁屏和全屏都不会暂停仍在运行的在线奖励、效果或探索。

### 金币消费与探索

- 商店除八件永久装扮外，新增 8 种可堆叠用品和 5 种可堆叠服务券；每种最多保存 99 件，单次可原子购买 1–10 件，购买后永久保存在背包直到主动使用。
- 基础恢复用品在目标属性已满或前置属性不足时不消耗；服务券即使属性已满仍可用于仪式和视觉体验。
- 限时效果按 `celebration`、`keyboard`、`mouse`、`theme`、`aura` 五个槽位 FIFO 排队；每槽最多 32 段、累计 14 个运行日，只消耗应用实际运行时间。
- 4 档探索委托同一时间只能进行一个。旅行期间保留大部分照顾、鼠标、键盘和拖动互动，旅行装暂时覆盖普通装扮但不改变已装备 ID；可提前返程，但不退款也不发奖励。
- 16 篇旅行故事优先选择尚未收集的条目；故事池收齐后按主进程提供的种子轮换。选中的故事随探索任务在出发时立即持久化，重启不会改抽。
- 正常完成时，旅行册、待确认故事、返程庆典效果和主题奖励原子写入；提前返程不发奖励，两种返程都不返金币、不增加经验或属性。

### 视觉、界面与发行配置

- 四个成长阶段现有 24 张本地 PNG：每阶段 1 张整图降级素材和身体、双臂、双腿 5 张 512×512 RGBA 分层素材；四阶段轮廓、叶片、色彩和闪耀效果具有更明显差异。
- 管理面板已拆分为状态、互动、生活和设置视图，生活页包含装扮、用品、服务、探索和背包；状态页显示成长称号、闪耀星、旅行和限时效果剩余运行时间。用品/服务的庆典、主题与光环，以及探索返程效果，均已映射到桌宠视觉。
- `dist:win` 现为 `dist:setup` 的别名，生成固定名 `小橙子桌宠-Setup-x64.exe`；`dist:update` 生成固定名 `小橙子桌宠-Update-x64.exe` 与 `update-manifest.json`。v1.2.0 不生成或发布 Portable。
- 2026-08-22 已通过 `npm.cmd test`（12 个测试文件、77 项测试）、完整 `npm.cmd run build` 及本地三件套 `npm.cmd run verify:release`。

## 已知实现与发行边界

- 全局键盘节奏依赖 `uiohook-napi` 原生组件。Setup 与 Update 已验证包含同一份解包后的 Windows x64 二进制；安装版在启用键盘互动后成功保持独立 Node utilityProcess 存活，并提供不可用降级。真实全局输入、停用、挂起恢复与退出清理仍需人工冒烟。
- 自动化测试不等于真实 Windows 窗口验收；桌面点击穿透、独立解锁按钮、全局输入、托盘、多显示器、DPI、全屏和挂起恢复仍需使用打包程序人工冒烟。
- v1.2.0 的固定名 Setup、Update 和清单已完成本地版本、大小、SHA-256、清单与原生二进制核对，但尚无远端 GitHub Release 资产与哈希证据；取得远端证据前不得创建正式 v1.2.0 发布快照或宣称发布闭环完成。
- 当前发行程序尚未代码签名，可能触发 Windows SmartScreen“未知发布者”提示；发布说明必须披露实际 `NotSigned` 状态。
- `compatibleFrom: 1.0.0` 已在 Windows x64 `10.0.26200` 的隔离目录通过 v1.0.0→v1.2.0 直升及 v1.0.0→v1.1.0→v1.2.0 累计安装；两条路径均验证丰富 schema 1 存档迁移和备份。
- 依赖声明仍使用 `latest`；本版可复现安装必须依赖已提交的 `package-lock.json` 和 `npm.cmd ci`。
- 仓库仍没有自动创建 GitHub Release、上传三件套或回读远端哈希的发布脚本。
