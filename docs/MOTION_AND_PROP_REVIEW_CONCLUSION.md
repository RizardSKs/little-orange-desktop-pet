## 1. 讨论结果

已完成人工传话 2/5 轮。双方已在主要方向上收敛，建议提前结束外部讨论。剩余问题需要用户偏好、素材测量和动态样片，而非更多文字评审。停止讨论不表示已获开发授权，也不表示 M1/M2 已执行。

共同认可：保持现有渲染基础；明确注意、接触、使用、收尾的因果；四项技术样板优先覆盖汽水、毛球、护理、键盘，饼干随后迁移；先以最简单可信的遮挡方式表达接触；长服务有开场、中段变化和收尾；成长与附件等待安全区间整套切换；强调动作短暂出现；原尺寸动态观察独立于数学和自动化验证。

## 2. Codex 对第二轮的修订

| 事项 | 最终判断 |
| --- | --- |
| A/B/C 定义 | 不将“缺证据”混入 C。方案类别与证据状态分列：A复用素材、B改分镜、C新增或拆片；另记待核实／技术核实／视觉核实 |
| 汽水杯沿到嘴、刷头贴身体 | 标为拟用 A 路线，不能因已有握点就声称这些用途接触已经正确实现 |
| 正常收尾必须完成 | 作为时间轴设计要求采纳。掉帧时直接求当前时间的姿态；若已越过总时长，直接结束，不延时、不补播终场、不重复结算 |
| 新动作等待旧退场 | 不设为强制串行。逻辑立即切新序列，允许旧物快照有界退出；是否短暂并存及遮挡须受控，不能拖延用户操作 |
| 旅行机制待核实 | 已在上一轮核实：旅行目标与成长均进入 VisualState 的资源加载和安全提交流程。其动态正确性仍需验证 |
| 长袖／宽袖风险 | 当前未核实有此类商品，不扩展目录。验收聚焦既有围巾、耳机、礼帽、皇冠和旅行装等真实附件 |
| 微动作一到主动作就停止 | 不机械禁止所有叠加。与用途相关的咀嚼、吞咽、表情可配合主动作；抑制无关且争夺注意力的运动 |
| 新增 PNG 需再次审批 | 列为待用户确认的本轮范围边界，不宣称仓库要求每张素材逐次审批。范围确认后，最小必要补图可在授权范围内执行 |

## 3. 分歧与待定事项

主要设计分歧已解决：对方认可现有成长安全提交基础，也认可短暂庆典跳步并非天然违规。上表是 Codex 对最终文字精度的修订，尚未由对方再次回复确认，不能称作逐字双方共识。

建议用户确认以下方案：

1. 技术样板采用汽水、毛球、护理、键盘；饼干紧随其后。若首批必须看到进食体验，可将饼干换入。
2. 允许主动庆典中的短促跳步、后坐或展臂，限制持续强运动与过量特效。
3. 允许在现有素材确实不能完成必要接触时最小补图／拆片；不大规模重画角色。

未确认前，这些是推荐方案；已确认后不应就相同范围反复要求许可。当前仍未开始开发。

## 4. 不可用文字评审替代的证据

待测四阶段真实 alpha 边界、关键道具可见范围、原尺寸接触和遮挡、完整长服务观感、真实 DPI／跨屏及掉帧表现。没有这些证据，素材类别不能升级成“视觉通过”，也不能承诺固定工作量或整体发布兼容。

已知源码基础来自上一轮只读核对；本轮未重新运行程序、测试、构建或安装。下一步若获准，先执行 M1 测量与动态基线，再据证据锁定样板分镜。
