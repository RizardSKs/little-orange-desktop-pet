## 2. 本轮核实到的源码事实

### 2.1 图层与素材能力

- `character.ts` 使用独立躯干、叶片、双臂、双腿和表情层；使用动作还会绘制 `segment.png` 与 `hand.png` 形成手臂和手掌。不能据此认定有独立手指握持或可独立转动的头部。
- 四阶段都有 `mouth-delighted.png`、`mouth-refreshed.png`。`pet-frame.ts` 仅在饼干／汽水的 attached 阶段加嘴部覆盖；覆盖使用固定用途嘴图，不等于任意表情都已有适配嘴图。
- 现有语义层从后往前包含身体、表情、叶片、前臂、前附件、持物、前手掌、嘴部遮挡和前特效。`Drawable.slot` 可逐帧改变，渲染以稳定 ID 保持元素；但当前多数物品一直在 heldObject，野餐场景在 backAccessory，不能说十三项已经具备完善的动态遮挡分镜。
- 改一个整体 PNG 的层级只能改变整张图的前后关系；同一物体同时绕过手掌前后，需要拆片或局部遮挡，不能用一个全局层序表达互相穿插。
- 护理已使用独立 `grooming-brush.png`；野餐已复用独立饼干片段作为手持食品。它们不是需要从零制作的能力。

### 2.2 五项候选的当前结构

| 候选 | 当前实现 | 尚不能据此声称成立的表现 |
| --- | --- | --- |
| 饼干 | 双手接触；attached 时身体轻微咀嚼压缩；嘴部覆盖 | 可见咬痕、独立嘴型咀嚼、原尺寸自然进食 |
| 汽水 | 双手握点、道具倾斜、身体轻倾、嘴部覆盖 | 杯沿精确碰嘴、一手放开擦嘴、独立仰头 |
| 毛球 | 自由／握持阶段切换，向角色目标点插值 | 独立地面滚动、碰撞触发反弹、手拍中后才变轨 |
| 护理 | 单手握刷柄，刷具独立片段 | 刷毛沿身体轮廓连续接触、多区域护理已经自然 |
| 键盘 | 固定场景矩阵，双手交替敲击，身体坐低 | 各阶段手落在真实键区、自然拉入、复杂坐姿已经验收 |

`geometry.ts` 在 512 逻辑空间里以 (256,480) 为身体旋转／缩放枢轴，再由阶段 displayMatrix 映射到窗口；不是简单绕图像中心缩放。键盘和野餐场景不继承身体摆动。

毛球／羽毛自由阶段虽输出场景矩阵，目标点和方向仍包含身体姿态计算；当前属于预编排插值，不是完全独立的物理运动。无需引入物理引擎，但后续必须定义拍中事件与轨迹改变的对应关系。

### 2.3 生命周期

| 事件 | 当前事实 | 下一版规划要求 |
| --- | --- | --- |
| 正常结束 | 主进程到期后 forceIdle，序列号改变；渲染按内部 cycleMs 循环，当前 ActionInput 不含整段总时长 | 收尾安排在到期之前；卡顿跳过关键帧时不延后结算、不补播完整成功仪式 |
| 拖动 | beginDrag 强制切换；不等待动作收尾 | 用户输入立即优先，不演正常终场 |
| 成功使用新物品 | 创建新序列与完整时长 | 旧动作安全退出，新动作不等待旧动作完整收尾 |
| 道具退出 | 持物／场景物从当前快照短暂淡出；自由物及装饰直接取消；减少动态效果时快照退出无持续时长 | 允许有界退场残影，不应把“没有旧层”错误定义成每次切换后一帧内绝对清零 |
| 成长变化 | 在线成长定时推进没有以 inventory-use 为暂停条件，因此可能与动作重叠；视觉资源加载后，只有 safe 且退出快照清空才能整套提交新阶段 | 延续安全点整套切换，不立即混换身体、尺寸、锚点与附件；无需等待整项长服务结束 |
| 旅行变化 | 同样进入 VisualState 加载与安全提交；旅行目标不显示永久装扮，但不改变装备所有权 | 保持语义，不以退场残影掩盖长期装备残留 |
| 资源失败 | 初始道具未就绪时改为待机求帧；角色失败用 fallback；附件失败可清空附件 | 不把降级称为专属动作完成，也不在渲染层重新结算或退款 |

现有 safe 判定包括周期初段和释放后的末段，并非字面上的“只在 release 后”；安全点能否适配新分镜必须重新验证。现有控制器和渲染循环没有“保证最后一帧展示后再结束”的握手，本轮不声称运行时每次都能看到完整末帧。

## 3. 尚未验证的证据

本轮只读源码与文件清单，没有运行程序、播放样片或修改素材。Python 启动器存在但没有已安装的 Python，因此未通过 Pillow 重新测量 alpha 边界；不把旧 tmp 证据当作本轮实测。

待补：五项道具真实 alpha 边界、四阶段组合姿态的窗口包围范围、手掌与物体接触的原尺寸视觉、DPI／跨屏、卡顿下的终场表现。文件存在和代码支持都不能单独证明 A 类“可自然实现”；素材分类必须允许“待核实”，不能强行猜成 A/B/C。

源码核实事实：

1. 当前独立层包括躯干、叶片、双臂、双腿、表情，以及动作使用的臂段和手掌 PNG；不能假定已有独立头部或握拳手指图。四阶段有两种用途嘴部遮挡图，饼干与汽水 attached 时使用固定对应图。

4. 毛球与羽毛自由阶段使用显式插值，目标仍由身体姿态影响；并非独立地面物理，也没有证据表明碰撞触发轨迹变化。后续可用确定性编排表现拍中因果，无需引入物理引擎。

7. 主进程到期直接切 idle，渲染内部循环尚无整段收尾合同；新分镜需在总时长结束之前完成正常收尾。拖动与新使用都改变序列，不等旧动作完整收尾。持物／场景物可短暂快照退场，自由物直接取消；中断不播放正常成功终场、不重复结算。
8. 真实 alpha 边界、原尺寸观感和 DPI 未在本轮实测，不能据源码给出“自然可用”的最终 A 类判定。请允许 A/B/C 表中出现待核实状态。
