# 架构与安全边界

> 文档级别：`LOCKED`  
> 修改权限：仅当用户在当前任务中明确点名本文件或明确授权改变架构与安全边界时可改；本次创建授权不延续到未来，普通“更新文档”不构成授权。  
> 适用版本：`1.1.0` 起，直至用户明确替换。  
> 最后核对日期：`2026-08-15`  
> 权威来源：用户明确决策；`src/main/main.ts`；`src/preload/preload.ts`；`src/shared/`；`src/renderer/`；`src/main/store.ts`；TypeScript 配置。  
> 更新触发：用户明确授权改变进程边界、安全配置、IPC 暴露面、持久化责任、网络边界或依赖安全策略时。

## 1. 进程职责

- Electron 主进程是特权边界和运行时状态的唯一所有者，负责窗口、托盘、系统能力、IPC 校验、存档和状态广播。
- preload 只通过 `contextBridge` 暴露经过类型定义和白名单限制的 `window.orangePet` API，不提供通用 IPC、文件系统、进程或 Node.js 访问。
- React 渲染层只负责视图、输入和反馈，不直接访问 Node.js、Electron 特权 API 或存档文件。
- `src/shared/` 领域层保持为无 Electron 依赖、无文件系统副作用的 TypeScript 规则与类型，供主进程、渲染层和测试复用。
- 状态修改必须沿“渲染层请求 → preload 白名单 → 主进程验证 → 领域规则 → 保存 → 广播”流动；渲染层不得成为持久状态权威。

新增功能优先沿用该分层。跨越边界或把特权能力下放给渲染层，属于架构安全变更，需要用户明确授权和风险说明。

## 2. Electron 安全配置

所有渲染窗口必须保持：

- `contextIsolation: true`
- `sandbox: true`
- `nodeIntegration: false`

不得为了开发便利关闭隔离、沙箱或启用 Node 集成。需要新系统能力时，应增加最小、专用、类型化的 preload 方法，并在主进程执行授权与参数校验。

## 3. IPC 规则

- 每个 IPC 通道只承担一个明确动作，不暴露任意通道转发器。
- 主进程不信任渲染层输入；动作名、设置键、字符串长度、枚举、坐标、物品 ID 和所有对象结构必须在执行副作用前校验。
- IPC 不接受任意文件路径、可执行文件、命令行或脚本内容。
- 错误必须以可理解且不泄露敏感路径、系统信息或内部堆栈的方式返回。
- 事件订阅必须提供解除订阅方式，窗口销毁后不得继续持有无效监听器。
- 公共 IPC 形状以共享 TypeScript 接口为准；新增或改变接口时同步类型、preload、主进程处理、调用方、测试和 `LIVING` 接口文档。

## 4. 持久化边界

- 存档只由主进程读写，位置固定在 Electron 用户数据目录。
- 保存流程保留临时文件、有效主档和备份恢复能力；写入前后的数据必须满足当前 schema 或经过显式迁移。
- 读取失败、校验失败和迁移失败必须区分处理；不得用默认档静默覆盖唯一旧档。
- 所有时间、数值、数组、标识符和设置在进入持久状态前都应限制到合法范围。
- 存档 schema 和迁移必须遵守 `RELEASE_AND_COMPATIBILITY.md`，并有从真实旧版样本升级的测试。

## 5. 本地与系统能力

- 应用不得发起产品运行所不需要的网络请求；不增加遥测、远程配置、自动更新或远程素材依赖。
- 调用操作系统能力应最小化权限和输入面。若使用子进程，只允许固定程序、固定用途和经过约束的参数；不得拼接来自渲染层或存档的任意命令。
- 开机启动、置顶、托盘、全屏检测等系统行为必须可预测，并尊重用户设置和完全退出。
- 不在日志、错误、IPC、文档或发布清单中输出密钥、令牌、凭据或个人数据。

## 6. 依赖和构建安全

- 新增依赖前检查是否确有必要、是否引入联网/遥测、所需权限、维护状态和许可证；优先使用现有能力或标准库。
- 安装和构建使用锁文件保证可复现；不得在不审查差异的情况下刷新全部依赖。
- 打包内容只包含运行所需的构建产物、素材和元数据，不夹带开发凭据、临时存档、测试数据或本机路径。
- 任何放宽安全配置、扩大 IPC 面或增加系统命令的修改必须配套负向测试，证明非法输入和越权路径会被拒绝。

## 7. 安全验证

涉及本文件边界的改动至少验证：

- 渲染层仍无法直接使用 Node.js 或文件系统。
- preload 只暴露预期 API，主进程拒绝错误类型、非法枚举、越界数值和未知 ID。
- 损坏存档、备份恢复和迁移失败不会造成静默数据覆盖。
- 新依赖和运行路径没有新增未经授权的网络、遥测或敏感信息输出。
- 生产构建保持窗口安全配置，并通过相关自动化测试与必要的人工冒烟检查。
