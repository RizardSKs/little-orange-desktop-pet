## 1. 产品定位

小橙子是一款以陪伴和温和养成为核心的 Windows 桌面宠物。主要体验必须保持轻量、可理解、无需账号且在本机独立运行。

## 2. 长期不变边界

- 应用默认且完整地离线工作，不依赖服务器、在线登录或远程配置才能使用核心功能。
- 不加入账号体系、广告、用户追踪、遥测、分析上报、付费、云存档或未经用户明确要求的网络请求。
- 不内置联网检查、自动下载或自动安装更新；正式更新通过用户取得并手动运行的离线安装包完成。
- 用户数据保存在本机用户数据目录，不随应用文件覆盖安装而重置，也不因普通卸载默认删除。
- 桌宠必须提供明确的完全退出方式；置顶、开机启动、自动散步等影响系统行为的能力必须由用户控制。
- 新功能不得以收集个人数据、削弱本地可用性或破坏已有存档为代价。

任何突破以上边界的改动都属于产品方向变更，必须由用户在当前任务中明确授权，并先说明数据、安全、兼容和退出方案。

## 3. 温和养成底线

- 照顾属性降低可以影响表情、反馈和收益效率，但不得导致角色死亡、永久离开、掉级或自动清空存档。
- 用户离开一段时间后应能继续陪伴和恢复，不以惩罚性机制强迫持续在线。
- 购买的本地装扮属于持久拥有内容；不得因普通更新、临时卸下或数值调整而无故丢失。
- 等级、经验、金币、已拥有装扮、当前装扮、设置和桌宠位置均属于需要保护的连续体验数据。

具体等级上限、经验公式、衰减速度、收益倍率、价格和动画参数属于 `LIVING` 配置，不在本文件固定；调整这些参数时仍须保持上述产品底线。

## 4. 平台和交互底线

- 官方目标平台为 Windows 10/11 x64；新增平台支持不得破坏 Windows 现有行为。
- 桌宠视图保持独立、透明、可拖动，并与管理面板、托盘入口和完全退出流程协同工作。
- 应尊重前台全屏场景、可见工作区和多显示器边界，避免桌宠阻挡或移动到用户无法找回的位置。
- 核心交互应有清晰反馈；失败不得静默扣除资源或损坏状态。

## 5. 数据和素材归属

- 运行时状态由本机应用管理，不把用户存档、操作记录或设备信息发送到外部服务。
- 素材必须随安装包本地提供；远程素材加载不能成为核心显示的依赖。
- 不得把密钥、令牌、私钥、凭据或用户隐私写入仓库、日志、文档或发布清单。
