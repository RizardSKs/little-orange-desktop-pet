## 快照结论

本地保留的两个 v1.0.0 Windows 发行物是一个 NSIS 安装包和一个 Portable 便携包。两个文件名都没有版本号后缀，但 Windows 文件元数据与内部 `app.asar` 均显示版本 `1.0.0`。

本快照只记录 2026-08-15 能从本地产物复核的事实，不把文件修改时间当作正式发行时间，也不根据当前源码反推 v1.0.0 的完整功能范围。
