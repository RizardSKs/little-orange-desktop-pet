## 用户可见变化

- 全部 8 种用品和 5 种服务改为逐项专属动作；成功使用时角色以对应表情、身体和四肢参与，不再只在角色旁边显示道具。
- 新增十二张柔和 3D 卡通风格透明动作道具，迷你键盘复用既有本地素材；动作支持四成长阶段、左右朝向、三档动画强度和减少动态效果。
- 使用失败不播放成功动作且不扣库存；成功动作只触发一次。拖动可安全打断，散步、键盘和鼠标环境互动在动作期间暂停，结束后恢复原状态。
- 瞬时使用动作与持续主题、光环和效果队列分离；旧存档中的庆典队列继续兼容。
- 新增用品与服务专属动作权威规格，并把专属动作、素材、规格和测试确立为以后新增或调整用品与服务的同任务完成条件。

## 实现偏离与已知限制

- 两个 EXE 未进行代码签名，Windows Defender 或 SmartScreen 可能显示未知发布者提示；Release 说明已明确披露。
- GitHub 大文件回下载在当前连接下长期无有效进度，Setup 与 Update 只取得不完整片段后停止；两份 EXE 采用 GitHub 资产 API 返回的可信服务器 `sha256`、名称和大小与本地逐项复核，不宣称完成全量回下载。manifest 已完整回下载并复核。

- Windows 10、其他 DPI、多显示器、SmartScreen 和真实系统电源事件仍属于人工补充冒烟边界。
- 应用不包含联网更新器、自动下载、遥测或输入内容采集；Update 是人工下载、完整离线、累计覆盖的安装程序。
