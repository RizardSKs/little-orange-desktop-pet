## 用户可见变化

- 成长上限扩展至 50 级，增加称号、六档闪耀星级、阶段化视觉与升级反馈。
- 增加持久桌面锁定、鼠标视线/拖拽互动和默认关闭、只统计节奏的隐私型键盘陪打。
- 增加用品、服务、背包、FIFO 限时效果与四条探索路线，提供自愿金币消耗渠道。
- 应用退出或系统挂起期间不再产生金币、经验、在线奖励周期、效果时间或探索进度；离线仅保留最多 8 小时属性衰减。
- schema 1 自动迁移到 schema 2；保留历史金币、八个稳定装扮 ID、装备、位置、设置与成长进度比例。
- v1.2.1 仅在 v1.2.0 功能候选基础上修正发布版本身份和 GitHub 兼容资产名。

## 实现偏离与已知限制

- 两个 EXE 未进行代码签名，Windows Defender 或 SmartScreen 可能显示未知发布者提示。
- Windows 10 客户端、真实桌面点击穿透、托盘、全局键盘钩子、SmartScreen、多显示器、DPI 和系统电源事件仍属于人工补充冒烟边界；自动测试和隔离启动不能完全替代这些场景。
- 应用不包含联网更新器或自动下载能力；Update 是人工下载、完整离线、累计覆盖的安装程序。
- 本次大文件远端全量回下载受到当前网络带宽限制；远端完整性依据 GitHub 服务器生成的资产 SHA-256 与本地最终构建摘要一致性确认。
