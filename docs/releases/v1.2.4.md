## 用户可见变化

- 四成长阶段改用独立左右肩部锚点，拖动、键盘和抓握动作中的手臂只围绕肩关节旋转；身体层继续遮住安全重叠接缝，移除了会拉开肩部的手臂平移。
- 拖动加入平滑速度、身体惯性滞后、急转侧倾、纵向拉伸、四肢速度反馈、释放横向缓冲和三段弹性落地；减少动态效果使用关节稳定的静态悬空姿态。
- 键盘陪打继续默认关闭并要求首次隐私确认；800ms 内累计三次按键后，以 `calm`、`steady`、`rapid` 节奏驱动双臂，停止约 900ms 后收起键盘，单次最长约 18 秒。
- 光标在手部区域停留约 250ms 后于 1.2 秒内外移至少 80px 可触发视觉抓握和宠物弹性跟随；应用不移动、锁定或拦截真实系统光标。
- 新增离线内置的 `mini-keyboard.png` 与 `cursor-grab.png` 透明素材，保持现有柔和 3D 卡通画风。

## 实现偏离与已知限制

- 两个 EXE 未进行代码签名，Windows Defender 或 SmartScreen 可能显示未知发布者提示；Release 说明已明确披露。
- 自动合成按键被全局钩子忽略，符合“不读取输入内容”的安全边界但不能替代人工敲击物理键盘；原生组件加载、授权保留、次数时间桶控制器及打包链已验证，物理键盘节奏仍列为人工补充冒烟边界。
- Windows 10 客户端、SmartScreen、多显示器、其他 DPI 和系统电源事件仍属于人工补充冒烟边界。
- `gh release download` 对两个大文件停在 0 字节，资产 API 单文件下载速度也不足以在本次闭环内完成；清单已实际回下载，两个 EXE 使用 GitHub 资产 API 返回的可信服务器 `sha256` 摘要、名称和大小与本地正式文件逐项复核。
- 应用不包含联网更新器、自动下载、遥测或输入内容采集；Update 是人工下载、完整离线、累计覆盖的安装程序。
