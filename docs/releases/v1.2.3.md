## 用户可见变化

- 拖拽互动加入方向、限幅速度和动画强度驱动的开心飞行姿态；身体前倾、四肢展开、兴奋表情与软弹落地均跟随实时拖动状态，减少动态效果模式取消持续摇摆。
- 八件永久装扮全部换为统一柔和哑光 3D 卡通风格的本地 512×512 RGBA PNG；四成长阶段共 32 组布局明确记录位置、宽度、旋转和层级，并跟随角色呼吸、行走、拖动和左右朝向。
- 托盘、应用菜单、宠物右键菜单和管理面板统一进入幂等退出流程；退出前停止周期、递归、移动、动作复位、鼠标采样、键盘工作进程和异步全屏结果，窗口销毁后清空引用。
- schema 2、应用 ID、用户数据目录、经济数值、单装扮槽位和八个稳定装扮 ID 保持不变；旅行装仍临时覆盖普通装扮。
