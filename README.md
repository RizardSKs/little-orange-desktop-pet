# 小橙子桌面宠物

小橙子是一只完全离线的 Windows 桌面宠物，支持日常照顾、成长、挂机收益、四阶段外观和装扮。应用不会联网检查、下载或自动安装更新。

> 文档级别：`LIVING`

> 适用版本：`1.1.0`

## 安装与更新

从 v1.1.0 起，每个正式版本应同时提供同一版本号的：

- `小橙子桌宠-Setup-x.y.z-x64.exe`：给新用户使用的最新完整安装包。
- `小橙子桌宠-Update-x.y.z-x64.exe`：给已安装旧版本用户使用的完整离线累积更新包。
- `update-manifest.json`：记录 Update 的版本、大小和 SHA-256。

新用户应直接安装最新版本的 Setup，不需要先安装 v1.0.0。已安装用户先正常退出小橙子，再运行目标版本的 Update；累积更新不要求逐个安装中间版本，但只能从该版本快照中已经实测声明的兼容版本升级。

Update 是完整的 NSIS 覆盖安装程序，不是联网下载器，也不是二进制差分补丁。用户数据保存在 Windows 用户数据目录而不是安装目录；正式发布前仍必须通过旧版覆盖安装验证存档连续性。

本地留存的 `小橙子桌宠-Portable-x64.exe` 是 v1.0.0 遗留便携版，仅供历史归档，不再更新，也不能使用 NSIS Update 原地升级。

当前保留的构建均未签名，Windows SmartScreen 可能显示未知发布者。请只运行来源可信且 SHA-256 与发布记录一致的文件。如果某个版本缺少同版本 Setup、Update 或清单，该发行集合是不完整的。

## 基本使用

- 单击小橙子打开管理面板。
- 拖动小橙子可调整位置。
- 右键小橙子或使用托盘图标可打开快捷菜单。
- 等级、金币、装扮、设置和位置保存在本机用户数据中。

## 开发入口

开发环境要求 Windows 10/11 x64、Node.js `22.12.0` 或更高版本。依赖安装应使用锁文件：

```powershell
npm.cmd ci
npm.cmd run dev
```

常用检查：

```powershell
npm.cmd test
npm.cmd run build
```
