# 小橙子桌面宠物

小橙子是一只完全离线的 Windows 桌面宠物，支持温和照顾、50 级成长、四阶段进化、桌面锁定、鼠标与键盘陪伴互动，以及用品、服务、探索和本地装扮。应用不需要账号，不会联网检查、下载或自动安装更新。

> 文档级别：`LIVING`  
> 修改权限：用户使用方式、开发环境或发布入口变化时与实现同步更新；不得在此放宽受保护准则。  
> 适用版本：`1.2.7`  
> 最后核对日期：`2026-09-14`  
> 权威来源：当前源码、`package.json`、实际发行物及 `docs/governance/` 中的受保护准则。  
> 更新触发：安装方式、基本交互、隐私说明、开发环境、发布组合或文档导航变化时。

## 主要功能

- 1–50 级成长：幼芽、活力、成熟、闪耀四阶段，20 级后每 5 级增加一颗闪耀星。
- 四阶段使用本地分层角色素材，每阶段都有整图降级、身体与四肢动作，以及 14 种图片表情；手、道具与装扮共享接触坐标。
- 单击抚摸、双击打开面板、连续点击躲闪；拖动时手臂保持连接身体，并根据平滑速度悬空摆动和惯性落地。
- 八件永久装扮使用随角色动作和朝向变化的本地透明 PNG，并按四个成长阶段分别校准位置与比例。
- 鼠标注视、靠近陪伴、扒拉、抓住光标并被带动、追逐和转晕等环境互动；不会控制或锁定真实系统光标。
- 键盘陪打启用后，连续敲击约三个键即可掏出本地小键盘，并按输入节奏一起敲击。
- 可持久化的桌面锁定：桌宠主体置顶且完全点击穿透，只能通过独立小锁、托盘或应用菜单解锁。
- 8 种用品、5 种服务券、背包、限时庆典/主题/光环，以及 4 档探索和 16 篇旅行故事；每种用品和服务都有角色实际参与的专属使用动作。
- 汽水会对准吸管饮用，毛球有滚动截停，护理穿插刷理与查看，键盘有交替敲击和停顿；四项动作在使用时长内完成收尾。
- 探索出发时就保存本次故事；未收齐时优先发现新故事，收齐后按主进程种子轮换。正常完成会同时加入返程庆典和主题奖励。
- schema 1 旧档自动迁移到 schema 2，保留等级、经验、金币、永久装扮、设置和位置，并在迁移前留下恢复备份。

金币和经验只在应用进程实际运行时产生。关闭应用或 Windows 进入睡眠、休眠等系统挂起期间没有金币和经验；返回后只结算最多 8 小时的照顾属性变化，限时效果和探索倒计时也在这些期间暂停。仅锁定 Windows 屏幕不会暂停仍在运行的在线奖励、效果或探索；锁屏会暂停原生键盘钩子与光标采样、收束鼠标环境位移互动并停止自动散步。

## 基本操作

- 单击小橙子：抚摸。
- 双击小橙子：打开管理面板。
- 连续点击三次或更多：小橙子会躲闪。
- 拖动小橙子：调整桌面位置，松手后立即保存。
- 右键小橙子或使用托盘：打开快捷菜单。
- 管理面板“生活”页：购买或使用装扮、用品、服务券，派遣探索并查看背包和旅行故事。
- 管理面板“设置”页：控制自动散步、散步活跃度、始终置顶、开机启动、鼠标互动、键盘陪打、动画强度和桌面锁定。

锁定后，小橙子不会响应点击、拖动或面板操作，鼠标会直接作用于下方软件。小橙子旁边的独立 🔓 按钮是主要解锁入口；托盘和应用菜单也提供解锁。

## 键盘陪打与隐私

键盘陪打默认关闭，首次开启会显示确认说明。该功能的本地原生组件只统计短时间桶内的按键次数和时间，用于判断“正在高频敲键盘”；它不会读取、传递或保存：

- 具体按键或字符；
- 密码、输入法内容或剪贴板；
- 活动窗口标题或正在编辑的内容。

统计只存在于当前运行内存中，不写入存档、不联网。关闭功能、退出应用、Windows 挂起或锁屏时会停止组件。如果当前电脑或安装包无法加载原生组件，界面会显示“组件不可用”，其他功能仍可正常启动和退出。

## 安装与更新

每个完成正式验证的版本只发布同一版本号的三件套：

- `Little-Orange-Desktop-Pet-Setup-x64.exe`：新安装使用的完整 NSIS 安装包。
- `Little-Orange-Desktop-Pet-Update-x64.exe`：已安装用户使用的完整离线累积更新包。
- `update-manifest.json`：记录 Update 的版本、大小和 SHA-256。

新用户直接运行最新 Setup。已安装用户应先从托盘完全退出小橙子，再运行兼容范围内的最新 Update；累积更新不需要依次安装中间版本。Update 不是联网下载器，也不是二进制差分补丁。

当前正式版本为 [v1.2.7](https://github.com/RizardSKs/little-orange-desktop-pet/releases/tag/v1.2.7)，完整校验信息见 [v1.2.7 发布快照](docs/releases/v1.2.7.md)。

v1.2.0 起不再构建或发布 Portable。历史留存的 v1.0.0 Portable 只作归档，不能用 Update 原地升级。

用户数据位于 Windows 用户数据目录而不是安装目录。正式发布前仍必须实际验证旧版覆盖安装，不能仅依靠目录配置推断兼容。

当前安装程序尚未代码签名，Windows SmartScreen 可能显示“未知发布者”。请只从可信 GitHub Release 获取文件，并核对版本快照或清单中的 SHA-256。如果某个版本缺少同版本 Setup、Update 或清单，它不是完整正式发行集合。

## 开发入口

开发环境要求 Windows 10/11 x64、Node.js `22.12.0` 或更高版本。依赖安装必须使用锁文件；键盘陪打使用的 `uiohook-napi` 是 Windows 原生依赖：

```powershell
npm.cmd ci
npm.cmd run dev
```

常用检查：

```powershell
npm.cmd test
npm.cmd run build
```

发行构建入口：

```powershell
npm.cmd run dist:setup
npm.cmd run dist:update
```

`dist:win` 当前是 `dist:setup` 的兼容别名；两者都只生成 Setup，不生成 Portable。
